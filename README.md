# 의료분쟁 사례집 편집기

Claude.ai 아티팩트로 만든 프로토타입을 VS Code에서 개발 가능한 형태로 옮긴 프로젝트입니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 표시되는 주소(보통 http://localhost:5173)로 접속하면 됩니다.

## 배포용 빌드

```bash
npm run build
```

`dist/` 폴더에 정적 파일이 생성됩니다. 이 폴더를 사내 웹서버에 올리거나,
더블클릭으로 바로 열리는 프로그램이 필요하면 Electron 등으로 감싸는 방법을
검토하시면 됩니다.

## 구조

- `src/App.jsx` — 메인 화면 (사례 등록/관리, 미리보기·발행)
- `src/storage.js` — 개인 작업본을 저장하는 유틸 (localStorage 기반)
- `src/main.jsx` — 진입점

## 로컬 AI(LM Studio) 연동으로 PDF 자동 요약·정리

"PDF에서 AI로 불러오기" 버튼을 쓰려면 먼저 LM Studio를 준비해야 합니다.

1. [LM Studio](https://lmstudio.ai)를 설치하고, 검색창에서 `EXAONE` 모델을 다운로드합니다.
   - GPU가 없는 컴퓨터라면 **EXAONE-4.0-1.2B**(GGUF, Q4_K_M)를 추천합니다.
2. LM Studio 왼쪽 `</>` 아이콘 → **Local Server** 탭에서 다운로드한 모델을 선택하고
   **Start Server**를 누릅니다. 기본 주소는 `http://localhost:1234` 입니다.
3. 이 앱의 툴바에서 톱니바퀴(설정) 아이콘을 눌러 서버 주소를 확인·저장합니다.
   기본값 그대로 두셔도 대부분 동작합니다.
4. "PDF에서 AI로 불러오기"로 문서를 올리면, 로컬 AI가 문서를 읽고
   ①사건 개요 ②주요 쟁점 ③결과 ④예방 포인트 형식의 JSON으로 정리해 폼에 채워줍니다.

**동작 원리 참고**
- 문서 전체가 앱 밖으로 나가지 않습니다. `fetch()` 요청은 오직
  `http://localhost:1234` (내 컴퓨터 안)로만 전송됩니다.
- LM Studio 서버가 꺼져 있거나 응답이 이상하면 자동으로
  규칙 기반 정리(①②③④ 제목 인식)로 대체되고, 이유가 화면에 안내됩니다.
- AI가 채워준 내용은 항상 저장 전에 검토해 주세요. 특히 작은 모델(1.2B)은
  가끔 문장을 요약하다 놓치는 부분이 있을 수 있습니다.

## PDF에서 사례 불러오기 (규칙 기반, AI 미사용 시)

"사례 관리" 탭의 "PDF에서 불러오기" 버튼으로 텍스트 기반 PDF를 업로드하면,
①사건 개요 ②주요 쟁점 ③결과 ④예방 포인트 제목을 기준으로 내용을 자동으로
나눠 새 사례 등록 폼에 채워줍니다. 규칙(정규식) 기반이라 다음 점을 참고하세요.

- 스캔 이미지로만 된 PDF(텍스트 선택이 안 되는 파일)는 인식하지 못합니다.
- 원본 문서가 ①②③④ 또는 "사건 개요" 같은 제목을 포함하고 있어야 정확히 나뉩니다.
- 자동으로 채워진 내용은 저장 전에 반드시 한 번 검토·수정해 주세요.
- HWP 파일은 지원하지 않습니다. 한/글에서 "다른 이름으로 저장" → PDF로 바꾼 뒤
  업로드해 주세요.

## 데이터 저장 방식

- 이 화면을 실행하는 브라우저의 `localStorage`에 개인 작업본이 자동 저장됩니다.
  (브라우저/컴퓨터를 바꾸면 데이터가 보이지 않으니, 필요하면 "작업 파일 내보내기"로
  파일을 백업해두세요.)
- 다른 담당자와는 "작업 파일 내보내기(.json)"로 파일을 전달하고,
  받는 쪽에서 "작업 파일 가져오기"로 병합합니다.
- 최종 사례집은 "사례집 미리보기·발행" 탭에서 PDF(인쇄) 또는 Word(.doc)로 내보냅니다.
